## Что проверено

### 1. Код очистки

В `tools/image-bg-removal/remove_bg.py` очистка проблемных зон теперь выполняется цветом:

```python
(255, 255, 255, 0)
```

Это лучше, чем прежний `(0, 0, 0, 0)`, потому что при ресайзе/композитинге прозрачные пиксели не дают чёрного RGB-ореола.

### 2. Контрольные точки PNG

Проверены пиксели в зоне бывшего чёрного прямоугольника:

```text
POINT 900,200 RGBA=255,255,255,0
POINT 900,500 RGBA=255,255,255,0
POINT 560,200 RGBA=255,255,255,0
POINT 950,650 RGBA=255,255,255,0
POINT 700,300 RGBA=255,255,255,0
POINT 850,300 RGBA=255,255,255,0
```

Результат: контрольные точки прозрачные и имеют белый RGB-подложечный цвет.

### 3. Региональная прозрачность

Проверена зона:

```text
x: 540..980
y: 80..710
```

Результат:

```text
ROI total=277200
transparent=261487
opaque=15713
transparentRatio=0.9433
blackTransparent=62
```

Прозрачность региона: `94.33%`, что совпадает с заявлением разработчика и выше порога `80%`.

Небольшое количество `blackTransparent=62` не воспроизводит прежний большой блок. Это не блокер, но при желании можно ужесточить тест до проверки RGB у прозрачных пикселей в будущей итерации.

### 4. Тесты добавлены

В `tools/image-bg-removal/tests/test_remove_bg.py` есть 4 теста:

```text
test_all_fixtures_processing
test_jack_stand_text_overlapping_fixed
test_jack_stand_annotation_background_is_transparent
test_redraw_annotations_cli_isolated
```

Новый тест `test_jack_stand_annotation_background_is_transparent` действительно проверяет контрольные точки и региональную прозрачность.

### 5. Кэш Python
