## Finding 1 — P1: В финальном PNG подставки остался большой чёрный непрозрачный блок

Файл:

`delivery/bg-removal/output/7138921733_w640_h640_podstavka-pod-mashinu.png`

Что видно при просмотре:

- справа от подставки, за стрелками и текстом `288-430 мм`, находится большой чёрный прямоугольник;
- он непрозрачный и будет виден на белых/светлых карточках товара;
- это ломает главную цель инструмента: получить чистую transparent PNG-графику товара.

Судя по коду, `redraw_jack_stand_annotations()` очищает зоны старой графики, но не гарантирует, что весь старый чёрный/тёмный прямоугольный фон аннотации становится прозрачным. Поэтому comparison sheet частично маскирует проблему на тёмном фоне, но в исходном output-файле дефект очевиден.

### Как исправить

В `tools/image-bg-removal/remove_bg.py` нужно отдельно очистить всю область старого правого annotation-panel до прозрачности перед дорисовкой новых линий/стрелок/текста.

Требование:

```text
После redraw_jack_stand_annotations() область вокруг размерной разметки должна быть прозрачной везде, кроме явно нарисованных новых векторных элементов:
- красная стрелка;
- серая стрелка;
- пунктирные линии;
- текст "288-430 мм".
```

Добавить точечные проверки пикселей, которые не должны принадлежать новым элементам:

```text
(900, 200) alpha == 0
(900, 500) alpha == 0
(560, 200) alpha == 0
(950, 650) alpha == 0
```

Координаты можно уточнить после финального макета, но смысл теста: он должен ловить именно большой залитый прямоугольник, а не только старую цифру.

## Finding 2 — P2: Текущий ROI-тест слишком узкий и не ловит главный визуальный дефект

Файл:

`tools/image-bg-removal/tests/test_remove_bg.py`

Текущий тест проверяет только ROI:

```python
roi_alpha = arr[360:430, 600:620, 3]
opaque_pixels = np.sum(roi_alpha > 10)
self.assertEqual(opaque_pixels, 0)
```

Эта проверка полезна для старой цифры `2`, но она не проверяет чистоту всей правой зоны аннотации. Поэтому тест может быть зелёным, даже если рядом остался большой непрозрачный прямоугольник.

### Как исправить

Добавить отдельный тест:

```python
def test_jack_stand_annotation_background_is_transparent(self):
    ...
    transparent_probe_points = [
        (900, 200),
        (900, 500),
        (560, 200),
        (950, 650),
    ]
    for x, y in transparent_probe_points:
        self.assertLess(arr[y, x, 3], 10, f"Expected transparent annotation background at {(x, y)}")
```

Лучше дополнительно добавить масочный тест по региону `x:540..980, y:80..710`, исключив зоны новых стрелок, пунктиров и текста.
