## Design Direction

Технічний е-commerce hero, не «маркетинговий банер». Енергія, на яку дивимось у Triniti SB, адаптована під спокійну сітку Elektronom:

- **Світло-блакитний технічний фон** (білий → `#E8EEF7`, `#F5F7FA`), без агресивного темно-синього.
- **Тонкі електричні мотиви** — сітка 40×40 px, DIN-рейка, схемні доріжки, синусоїда. Окремий мотив на кожен слайд, щоб карусель не виглядала однотипно.
- **Крупний товар праворуч** + 2 floating stat-cards, які підкреслюють найважливіші числа з картки.
- **Інфографічні chips** під сабтайтлом — компактні, з табулярними цифрами, моноспейс не потрібний.
- **Solid синій CTA `#3B7BD9`** + secondary text link з нижнім бордером (стиль сайту).
- **Карусельний chrome** — білі круги-стрілки 40 px зі shadow-sm + 4 крапки, активна → синя капсула 24 px.

Що навмисно НЕ робимо: ніяких градієнтів-blob, без AI-orbs, без bokeh, без фотостоку з людьми, без ALL-CAPS у хедлайнах, без емодзі, без 3D-іконок, без жовтих/червоних плашок «-50%».

Сітка:

- зовнішня карточка 1440 × 420, radius 8 px, border `#E6EAF0`;
- ліва колонка ~55 % шириною, паддінг `44 / 32 / 44 / 56` px;
- права колонка ~45 %, паддінг `32 / 56 / 32 / 16`;
- товар по центру правої колонки, 2 stat-cards закріплені у `top:14% right:4%` та `bottom:18% right:2%`;
- стрілки каруселі — 40 px кола, `left:16px / right:16px`;
- крапки — `bottom:16px`, центр.

**Export-friendly розміри (рекомендую готувати в Figma):**
- `1440 × 420` (основний),
- `1536 × 448` (на широкі екрани),
- `1020 × 320` (compact — варіант A · compact в превʼю).

Усі слайди (A/B/C/D) використовують **однакову сітку** та один CTA-стиль — карусель залишається консистентною.

### Шари / Figma layer order
Знизу вгору:
1. `bg` — флет fill + SVG-grid/circuit
2. `accent-stripes` — акцентні лінії `#3B7BD9 @ 18%`
3. `product-shadow` — еліпс під товаром
4. `product-image`
5. `stat-cards` — позиціонуються absolute відносно `.hero-banner__stage`
6. `text-layer` — badge, h1, sub, chips, CTA
7. `chrome` — стрілки каруселі, крапки

### Стани

| Стан | Що змінюється |
|---|---|
| Default | як на макеті |
| Hover на CTA | `background: var(--accent-hover)`; transition 120 ms |
| Active | `background: var(--accent-press)` |
| Hover на стрілку | `background: var(--surface-alt)` + shadow-md |
| Focus-visible | `outline: 2px solid var(--accent); outline-offset: 2px` |
| Без зображення товару | приховуємо `.hero-banner__stage`, ліва колонка займає 100 % |
| `availability === false` | ховаємо `chip--success` (не показуємо «Немає в наявності» на промо) |

### Інтеграція в карусель
- 4 слайди в DOM від старту, без auto-rotate (бренд-рекомендація: «no auto-rotating carousels»);
- swipe на mobile, клавіатура `←/→`, focus-trap не потрібен;
- ARIA: `<div role="region" aria-roledescription="карусель" aria-label="Акції та новинки">`;
- кожен слайд — `<li role="group" aria-roledescription="слайд" aria-label="1 з 4">`.

### Performance
- Усі продукти → `loading="eager"` лише на першому слайді, решта — `loading="lazy"`.
- SVG-фони — inline (≤ 4 KB кожен), не блокують render.
- Один webfont (Inter) — вже завантажується на сайті, додаткового запиту не треба.
