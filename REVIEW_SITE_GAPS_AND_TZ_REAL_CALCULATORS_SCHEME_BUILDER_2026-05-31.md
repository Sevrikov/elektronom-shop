## Главный модуль: схемостроение низковольтной электрики

Название: “Схема квартиры/дома”  
Назначение: пользователь вводит параметры объекта, система строит группы линий, рекомендует кабель, автоматы, УЗО/дифы, щит, расходные материалы и формирует BOM по каталогу.

Важно: это не проектная документация для монтажа, а предварительный расчет и подбор товаров. В интерфейсе обязательно показывать предупреждение: финальное решение должен проверить квалифицированный электрик/проектировщик.

### Входные данные

Объект:

- квартира / частный дом / офис / гараж / мастерская;
- площадь, м²;
- количество комнат;
- количество санузлов;
- кухня: обычная / электроплита / духовой шкаф / посудомойка;
- отопление: нет / электрокотел / теплый пол / бойлер;
- сеть: 1 фаза 230 В / 3 фазы 400 В;
- вводной автомат или лимит мощности;
- тип прокладки: скрытая / открытая / гофра / кабель-канал;
- материал кабеля: медь по умолчанию;
- запас: стандарт / усиленный / премиум.

Помещения:

- гостиная;
- спальня;
- кухня;
- ванная;
- коридор;
- балкон;
- котельная;
- гараж;
- пользовательские помещения.

Нагрузки:

- освещение;
- розетки общие;
- холодильник;
- стиральная машина;
- бойлер;
- посудомойка;
- электроплита;
- духовой шкаф;
- кондиционер;
- теплый пол;
- роутер/слаботочка;
- видеонаблюдение;
- сервер/UPS;
- резервные линии.

## Расчетные правила MVP

### 1. Расчет тока

Формула:

```text
I = P / U
```

Для однофазной сети:

```text
I = P / 230
```

Для трехфазной сети:

```text
I = P / (sqrt(3) * 400 * cosφ)
```

Для MVP можно принять `cosφ = 0.95`, но показывать его как настройку.

### 2. Подбор кабеля

MVP-правила:

- освещение: 3x1.5 мм², автомат 10А;
- розетки: 3x2.5 мм², автомат 16А;
- бойлер/стиральная/посудомойка: отдельная линия 3x2.5 мм², автомат 16А, УЗО/диф 30 мА;
- духовой шкаф: 3x2.5 или 3x4 мм² по мощности;
- электроплита: 3x6 мм² или 5x6 мм², автомат 32А, отдельная защита;
- теплый пол: отдельная линия + УЗО/диф 30 мА;
- мокрые зоны: обязательная дифференциальная защита 30 мА.

Дополнительно:

- учитывать длину линии и падение напряжения;
- если падение напряжения выше допустимого порога, повышать сечение;
- показывать причину: “2.5 мм² не проходит по падению напряжения, предложено 4 мм²”.

### 3. Подбор автомата

Правила:

- номинал автомата не должен превышать допустимый ток кабеля;
- типовая кривая для бытовых линий: C;
- освещение: C10;
- розетки: C16;
- мощные потребители: C16/C20/C25/C32 по расчету и кабелю;
- вводной автомат зависит от лимита мощности и сети.

### 4. Подбор УЗО/дифавтомата

Правила:

- санузел/ванная/мокрые зоны: 30 мА;
- розеточные группы: 30 мА;
- вводное селективное УЗО: опционально 100/300 мА по сценарию;
- ток УЗО должен быть не ниже автомата группы или согласован с вышестоящей защитой;
- для важных линий можно предложить дифавтомат вместо автомат + УЗО.

### 5. Подбор щита

Расчет модулей:

- автомат 1P: 1 модуль;
- автомат 2P: 2 модуля;
- дифавтомат 1P+N: обычно 2 модуля;
- УЗО 2P: 2 модуля;
- реле напряжения: 2-3 модуля;
- счетчик/контактор/реле: по конфигурации;
- запас по модулям: минимум 20-30%.

Результат:

- рекомендовать щит на N модулей;
- показать занятые/свободные модули;
- предложить DIN-рейки, шины N/PE, гребенки, маркировку, наконечники.

## Схемостроение

Нужен визуальный конструктор схемы:

```text
Ввод -> вводной автомат -> реле напряжения -> УЗО/дифы -> группы линий -> нагрузки
```

### Вид схемы

Desktop:

- левая панель: параметры объекта;
- центр: схема щита и групп;
- правая панель: BOM/товары/цена;
- нижняя панель: предупреждения и ошибки.

Mobile:

- шаговый мастер;
- вкладки: “Параметры”, “Схема”, “Товары”, “Проверка”.

### Элементы схемы

- ввод;
- счетчик/лимит;
- вводной автомат;
- реле напряжения;
- УЗО;
- дифавтомат;
- групповой автомат;
- линия кабеля;
- помещение;
- нагрузка;
- резервная линия.

### Интерактивность

## Реальные калькуляторы

### 1. Калькулятор кабеля

Вход:

- мощность, Вт/кВт;
- напряжение 230/400 В;
- длина линии;
- материал;
- тип прокладки;
- однофазная/трехфазная;
- допустимое падение напряжения.

Выход:

- ток;
- минимальное сечение;
- рекомендуемое сечение;
- падение напряжения;
- рекомендуемый кабель из каталога;
- предупреждение, если вводные некорректны.

Каталог:

- искать в категориях “Кабель та провід”;
- фильтровать по сечению, жилам, материалу, наличию;
- показывать 3 варианта: эконом / стандарт / премиум.

### 2. Калькулятор автомата

Вход:

- мощность нагрузки;
- тип нагрузки;
- кабель;
- фаза;
- категория помещения.

Выход:

- рекомендуемый номинал;
- кривая B/C/D;
- полюсность 1P/2P/3P/4P;
- товары из категории автоматов;
- предупреждение, если автомат больше допустимого для кабеля.

### 3. Калькулятор УЗО/дифа

Вход:

- группа линии;
- помещение;
- ток автомата;
- мокрая зона да/нет;
- тип нагрузки.

Выход:

- УЗО или дифавтомат;
- ток утечки 10/30/100/300 мА;
- номинальный ток;
- тип AC/A/F, если данные есть;
- товары из каталога.

### 4. Калькулятор UPS/резервного питания

Вход:

- список нагрузок;
- мощность каждой;
- желаемое время автономии;
- тип АКБ;
- запас.

Выход:

- суммарная мощность;
- емкость АКБ;
- рекомендуемый UPS/инвертор;
- аккумуляторы;
- кабели/защита;
- ориентировочное время работы.

### 5. Калькулятор освещения

Вход:

- площадь помещения;
- тип помещения;
- высота потолка;
- желаемая освещенность;
- тип светильника.

Выход:

- нужные люмены;
- количество светильников;
- мощность;
- товары из каталога.

## Интеграция с каталогом

Калькуляторы не должны выдавать абстрактные рекомендации без товаров.

Для каждого результата:

- найти товары в каталоге;
- учитывать `isActive`;
- учитывать `stock`;
- показывать цену;
- показывать альтернативы;
- показывать почему выбран этот товар;
- давать кнопку “Добавить в проект”;
- давать кнопку “Добавить все в корзину”.

Нужен общий слой:

```ts
type EngineeringRecommendation = {
  groupId: string
  role: 'cable' | 'breaker' | 'rcd' | 'panel' | 'accessory'
  requiredSpec: Record<string, string | number | boolean>
  productId?: string
  alternatives: string[]
  reason: string
  warnings: string[]
}
```
