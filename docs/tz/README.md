# ТЗ проекта Elektronom

Дата актуализации: 2026-05-21  
Базовый протокол: `MASTER_CONTEXT v1_02.md`, версия 1.3  
Стек: Next.js 16.2.3, React 19.2.4, TypeScript, Tailwind CSS v4, Prisma 7.8.0, Zustand 5.0.13

## Назначение папки

Эта папка собирает все технические задания проекта в одном месте внутри рабочей папки сайта. Оригинальные файлы из внешней папки Antigravity сохранены без правок в `docs/tz/original/`. Рабочие файлы ниже обновлены под текущий `MASTER_CONTEXT v1_02.md` и фактическое состояние проекта.

## Порядок чтения и выполнения

1. `TZ_00_SUMMARY.md` — сводка, статус проекта и последовательность работ.
2. `TZ_01_STATUS_AND_SCOPE.md` — что уже реализовано, что считается незавершённым, границы задачи.
3. `TZ_02_BACKEND_PROTOCOL.md` — backend, Prisma 7, Server Actions, seed, Algolia, auth, env.
4. `TZ_03_FRONTEND_ROUTES_COMPONENTS.md` — страницы, компоненты, Server/Client Components, пользовательские сценарии.
5. `TZ_04_DESIGN_SYSTEM.md` — правила дизайна, Tailwind v4, адаптивность, запреты по стилям.
6. `TZ_05_ACCEPTANCE_CHECKLIST.md` — чеклист приёмки перед сдачей.
7. `TZ_06_ORIGINAL_COVERAGE_MATRIX.md` — сверка старых частей ТЗ с обновлёнными файлами.

## Главные правила

- `MASTER_CONTEXT v1_02.md` версии 1.3 имеет приоритет над старым ТЗ.
- Если старый документ требует Prisma 6/Zustand 4 или ссылается на MASTER v1.2, это считается устаревшим.
- Любая новая разработка должна учитывать `AGENTS.md`: перед изменением кода Next.js 16 нужно сверяться с локальной документацией Next.js в `node_modules/next/dist/docs/`.
- Оригиналы в `original/` нужны только для истории и сравнения, не как рабочий план.
- Если разработчику нужен максимально детальный список из старого ТЗ, он должен смотреть `TZ_06_ORIGINAL_COVERAGE_MATRIX.md`: там указано, куда перенесён каждый крупный блок и что было исправлено.
