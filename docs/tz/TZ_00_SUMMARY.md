## Что считать готовым

Готовность означает не только `npm run build`, но и рабочий пользовательский путь: покупатель может найти товар, открыть карточку, добавить в корзину, оформить заказ, получить корректное состояние заказа, а администратор может увидеть и обработать этот заказ.

## Критические правила из исходного сводного ТЗ

Эти пункты перенесены из старого `ТЗ_СВОДНОЕ.md` и остаются обязательными, но трактуются через MASTER v1.3:

- новые исходники только `.ts` / `.tsx`, без новых `.js` файлов в app/src/runtime коде;
- не использовать `any` как способ обойти типизацию;
- `'use client'` ставить только там, где реально нужны события, состояние браузера, формы или эффекты;
- `middleware.ts` не возвращать, файл маршрутизации остаётся `proxy.ts`;
- Prisma в runtime использовать через `import { prisma } from "@/lib/prisma"`;
- не делать `findMany()` без лимита `take`, если это не доказано безопасный служебный случай;
- `ALGOLIA_ADMIN_KEY` никогда не должен быть `NEXT_PUBLIC_*`;
- все пользовательские строки интерфейса должны идти через `next-intl`;
- изображения выводить через `next/image` с `alt` и `sizes`;
- перед изменением Next.js 16 API сверяться с локальной документацией из `node_modules/next/dist/docs/`.
