## КРИТИЧНІ ВИМОГИ (з MASTER_CONTEXT v1.2)

- ⛔ Ніяких `.js` файлів — тільки `.ts` / `.tsx`
- ⛔ Ніякого `any` в TypeScript
- ⛔ `'use client'` тільки де необхідна інтерактивність
- ⛔ `export const revalidate` → замінити на `'use cache'` + `cacheLife()`
- ⛔ `middleware.ts` → файл називається `proxy.ts`
- ⛔ Нові `PrismaClient()` → тільки `import { prisma } from '@/lib/prisma'`
- ⛔ `findMany()` без `take` → обов'язковий ліміт
- ⛔ `ALGOLIA_ADMIN_KEY` → ніколи не в `NEXT_PUBLIC_*`
- ✅ Кожна строка інтерфейсу → через `t()` з next-intl
- ✅ Усі зображення → через `next/image` з `alt` і `sizes`
