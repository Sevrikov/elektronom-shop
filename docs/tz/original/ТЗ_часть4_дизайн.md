## 23. ТИПОГРАФИКА

### 23.1 Шкала

| Роль | Шрифт | Размер | Line-h | Weight | Использование |
|------|-------|--------|--------|--------|--------------|
| H1 / Display | Inter Tight | 32px | 40px | 700 | Заголовок страницы |
| H2 | Inter | 24px | 32px | 600 | Секционные заголовки |
| H3 | Inter | 18px | 26px | 600 | Подзаголовки |
| Body Regular | Inter | 15px | 22px | 400 | Описание товара |
| Body Bold | Inter | 15px | 22px | 600 | Акцентный текст |
| UI Default | Inter | 14px | 20px | 400/500 | Навигация, пункты меню |
| Small | Inter | 13px | 20px | 400 | SKU, мета-текст |
| Micro | Inter | 11px | 16px | 500 | Labels UPPERCASE, chips |
| Price | Inter | 18px | 22px | 700 | Цена товара в карточке |
| Price Large | Inter | 24px | 30px | 700 | Цена на странице товара |

### 23.2 Правила

- **Inter** — весь UI, тело
- **Inter Tight** — только логотип и H1/Display заголовки
- **JetBrains Mono** — BOM-конфигуратор, textarea списка SKU
- Числовые данные (цена, SKU, MPN, количество) — `tabular-nums`
- Micro / Label — `text-transform: uppercase; letter-spacing: 0.04em`
- Hardcode шрифтов через `<link>` — ⛔ ЗАПРЕЩЕНО. Только `next/font`

## 26. ОПТОВАЯ ЛОГИКА (Quantity Breaks)

```
Tier 1: 1–9  шт  → базовая цена
Tier 2: 10–49 шт → -6% (или указывается индивидуально)
Tier 3: 50–199 шт → -12%
Tier 4: 200+ шт  → -18%

Отображение в карточке: "від 10 шт −6%" (11px, 500, accent)
Хранение в БД: Product.attributes JSONB:
  { "qty_breaks": [{"min":10,"discount":6},{"min":50,"discount":12}] }

На странице товара — таблица ценовых тиров:
  | Від | Ціна за шт | Знижка |
  |-----|-----------|--------|
```

## 27. АНИМАЦИИ И TRANSITION

```css
/* Стандартные переходы */
--dur-fast:   120ms;  /* кнопки, hover */
--dur-normal: 200ms;  /* drawer, dropdown */
--dur-slow:   300ms;  /* slide-in, carousel */

/* Применение */
button:    transition: background var(--dur-fast) ease;
card:      transition: box-shadow var(--dur-fast) ease;
drawer:    transition: height var(--dur-normal) ease;
image:     transition: transform var(--dur-slow) ease; /* hover zoom */
tab:       transition: color var(--dur-fast) ease;
```

## 31. CHECKLIST ДЛЯ АГЕНТОВ — ДИЗАЙН

```
□ Используешь CSS-переменные из @theme, не хардкодишь hex
□ Цвет accent = #3B7BD9, никаких других синих
□ Шрифт Inter через next/font (не <link> в <head>)
□ Inter Tight — только логотип и H1
□ Числа (цена, SKU) — tabular-nums
□ Hover на карточке: shadow-md (не border)
□ Active состояние cat-row: inset-shadow 2px accent
□ stock-pill: success-subtle bg + success dot + success text
□ Кнопки: transition 120ms, не мгновенно
□ Mobile: tab bar 64px фиксированный снизу, pb-16 для контента
□ Иконки Lucide: stroke-width 1.5 (UI) или 2 (акции)
□ Logo bolt: bg=accent, radius=4px, icon zap white
□ Footer bg = #1A1F2B (не Tailwind gray-900)
□ Page bg = #E9EDF2 (не white)
□ Нет style={{}}, только Tailwind классы с CSS-переменными
```
