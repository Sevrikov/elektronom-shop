# ТЗ: Система уникальных монохромно-трёхцветных символов для Мега-Меню и Каталога (Электрика и смежные группы)

> **Статус**: Внедрено / Спецификация деплоя v3.0  
> **Стандарт визуализации**: ELEKTRONOM Concept 3 ("Classic Hero")  
> **Палитра**: Грифельный серый (`#90A1B9`), Фирменный синий (`#155DFC`), Изумрудный акцент (`#00BC7D`)

---

## 1. Цель и бизнес-задача

Каждая позиция выпадающего Мега-Меню и Сайдбара каталога на сайте **ELEKTRONOM** должна быть наглядно идентифицируема уникальной SVG-иконкой. Ни одна группа или подгруппа не должна использовать дефолтную иконку-заглушку. 

Пользователь при наведении на категорию или скролле меню должен с первого взгляда считывать конструктивные особенности электротехнического оборудования:
- **Корпуса и оболочки** → Грифельно-серый базовый силуэт (`#90A1B9`).
- **Рабочая начинка / механизмы / контакты** → Синий цвет (`#155DFC`).
- **Светодиоды / статусы / безопасность** → Изумрудный зелёный акцент (`#00BC7D`).

---

## 2. Общие технические требования к иконкам

1. **Модульная сетка**:
   - Корневые группы (Класс A): `viewBox="0 0 24 24"`, толщина штриха `strokeWidth="1.8px"` (относительно 24px).
   - Подгруппы номенклатуры (Класс B): `viewBox="0 0 16 16"`, толщина штриха `strokeWidth="1.6px"` (относительно 16px).
2. **Типографика штриха**: `strokeLinecap="round"`, `strokeLinejoin="round"`.
3. **Производительность**: Рендеринг исключительно через чистые inline SVG-компоненты React (`CategoryIcon`), без внешней загрузки картинок `.png`/`.svg`.

## 4. Контракт реализации в коде (`CategoryIcon.tsx`)

Для предотвращения совпадений и «падения» в дефолтную иконку, алгоритм сопоставления ключевых слов в `src/components/ui/category-icon.tsx` построен строго от **конкретных подкатегорий к широким категориям**:

```tsx
// Пример приоритета сопоставления:
// 1. Проверяются специфичные подкатегории
if (s.includes('dif') || s.includes('uzo')) return <RcdIcon />
if (s.includes('avtomat') && !s.includes('root')) return <McbIcon />
if (s.includes('rele')) return <RelayIcon />
if (s.includes('utp') || s.includes('vytaya')) return <UtpIcon />

// 2. Только если подкатегория не совпала — применяется родительская группа
if (s.includes('elektr') || s.includes('electr')) return <ElectricalRootIcon />
```

## 5. Чек-лист проверки для разработчиков

- [x] **100% покрытие номенклатуры**: Ни одна ссылка в Мега-Меню не отображает стандартный `File` или `Image` placeholder.
- [x] **Мобильная адаптивность**: В мобильном шторке каталога (Mobile Drawer) вместо статических картинок используются идентичные векторы `<CategoryIcon slug={cat.slug} />`.
- [x] **Dark Mode**: Серые элементы адаптивно переключаются на `dark:stroke-slate-400`, а синяя начинка — на `dark:stroke-[#51A2FF]`.
- [x] **Производительность**: Размер компонента минимален, SVGs рендерятся монолитно без дополнительных сетевых HTTP-запросов.
