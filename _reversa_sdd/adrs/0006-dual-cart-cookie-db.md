# ADR-0006 — Двухрежимная корзина: cookie для гостя, БД для авторизованного, merge при входе

**Статус:** Принято · 🟢 подтверждено кодом

## Контекст
Корзина нужна и гостям (без регистрации), и авторизованным (с переносом между устройствами). Состояние должно быть надёжным (не только клиентским).

## Решение
- Гость → httpOnly-cookie `cart` (JSON, 30 дней, валидируется при чтении).
- Авторизованный → таблица `CartItem`.
- При входе `mergeCartIfNeeded` сливает cookie в БД (`qty = min(existing+new, stock, 99)`), затем очищает cookie.
- **Zustand хранит только UI** (открытие drawer + `cartVersion` для триггера ре-фетча), не данные.

## Последствия
- ➕ Чистое разделение: источник истины — сервер; устойчиво к манипуляциям на клиенте.
- ➕ Бесшовный перенос гостевой корзины при логине.
- ➖ httpOnly-cookie недоступен из JS → каждое изменение идёт через server action + `revalidateTag('cart')`.
- ➖ Нет TTL-очистки «брошенных» серверных корзин.
