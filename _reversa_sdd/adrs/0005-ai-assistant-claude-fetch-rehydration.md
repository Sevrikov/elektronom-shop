# ADR-0005 — AI-ассистент: прямой вызов Claude + регидратация из БД (без векторного RAG)

**Статус:** Принято (MVP) · 🟢 подтверждено кодом · git `240f888`

## Контекст
Нужен технический консультант: подбор оборудования, сравнение, черновик заказа. В схеме заложены `TechnicalDocument`/`DocumentChunk`/`embedding` под RAG.

## Решение
Реализован **keyword-retrieval по товарам** (Prisma) + **prompt-stuffing** каталога в системный промпт, затем **прямой `fetch`** к Anthropic (`claude-3-5-sonnet-20241022`). Ответ валидируется zod и **регидратируется из БД** (цена/наличие/имя — из `dbProducts`, не от LLM). При отсутствии ключа — захардкоженный «[Демо-режим]».

## Последствия
- ➕ **Регидратация** исключает галлюцинации цен/наличия (сильная сторона, BR-AS-3).
- ➕ Защита: фильтры prompt-injection, лимит длины, усечение истории, учёт стоимости.
- ➖ **Векторный RAG не реализован**: `embedding`/`DocumentChunk`/`TechnicalDocument` не используются (🔴 AS-1); «sources» — плейсхолдеры (🔴 AS-5).
- ➖ `ANTHROPIC_API_KEY` вне `.env.example` и `env.ts` (🔴 AS-2/CI-3); прямой fetch без SDK/ретраев (🟡 AS-6).
- ➖ Rate limit на скане БД, IP в открытом JSON (🟡 AS-5/AS-7).

## Альтернативы
pgvector + эмбеддинги (полноценный RAG), официальный `@anthropic-ai/sdk` с tool-use вместо JSON-парсинга.
