# ADR-0007 — Снапшоты данных в заказе

**Статус:** Принято · 🟢 подтверждено кодом

## Контекст
Цена, имя и состав товара меняются со временем; покупатель может быть гостем; товар может быть удалён. Заказ обязан оставаться достоверным историческим документом.

## Решение
- `Order.customerData Json` — снапшот покупателя (имя/email/телефон/адрес) на момент заказа.
- `OrderItem.snapshot Json` — снапшот позиции (name/sku/image/price), плюс `OrderItem.price` фиксируется отдельно.
- Связи `Order.userId`/`OrderItem.productId` — `SetNull` при удалении (заказ выживает).

## Последствия
- ➕ Заказ неизменен при изменении/удалении товара или пользователя.
- ➕ Поддержка гостевых заказов (`userId=null`).
- ➖ Дублирование данных (приемлемо и желательно для истории).
- ➖ `Order.addressId` фактически не заполняется — адрес живёт только в `customerData` (🟡 O-5), поэтому связь `address` в выборках пустая.
