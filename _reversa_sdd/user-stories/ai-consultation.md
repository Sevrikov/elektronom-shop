# User Story — Консультация с AI-ассистентом

> Артефакт **Writer** (`completo`) · Reversa. 🟢 из кода.

## Действующие лица
Гость / CUSTOMER.

## История
> Как покупатель, я хочу описать техническую задачу (например, резервное питание роутера) и получить подбор оборудования с расчётом, чтобы сформировать корзину.

## Основной сценарий (happy path)
1. Пользователь открывает `/assistant`, пишет запрос (≤800 символов). *(assistant)*
2. API проверяет rate-limit и prompt-injection, создаёт/находит сессию, логирует сообщение.
3. `queryAssistant`: keyword-поиск товаров → prompt-stuffing → Claude → JSON → zod.
4. **Регидратация из БД**: товары/черновик берут цену/наличие из БД (не из LLM).
5. Ответ: текст + рекомендованные товары + черновик заказа/сравнение + warnings + источники + оценка стоимости.

## Сценарии отказа / граничные
- **Prompt-injection:** запрос с «ignore prior instructions» → 400.
- **Превышение лимита частоты:** 2-е сообщение <2с → 429.
- **Нет API-ключа:** ответ «[Демо-режим]» (canned).
- **LLM вернул невалидный JSON:** fallback на локальный матчер.

## Связанные требования
FR-AS-1..8, AC-AS-1..4.

## Пробелы 🔴
- «RAG» не векторный (embedding/DocumentChunk не используются).
- Источники (sources) — захардкоженные плейсхолдеры, не реальная техдокументация.
- `ANTHROPIC_API_KEY` вне валидации env; IP в открытом виде в логах.
