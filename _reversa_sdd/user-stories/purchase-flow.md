# User Story — Покупка товара (гость и авторизованный)

> Артефакт **Writer** (`completo`) · Reversa. 🟢 из кода.

## Действующие лица
Гость / CUSTOMER.

## История
> Как покупатель, я хочу найти товар, добавить в корзину и оформить заказ, чтобы получить продукцию с доставкой.

## Основной сценарий (happy path)
1. Покупатель открывает категорию, применяет фасетные фильтры (бренд/цена/атрибуты) → видит реактивные счётчики. *(catalog)*
2. Открывает карточку товара, видит цену/наличие/характеристики/опт-цены. *(product)*
3. «В корзину» — `addToCart` (гость → cookie, авторизованный → БД), qty ≤ stock. *(cart)*
4. Переходит в checkout, заполняет контакты/адрес, выбирает способ оплаты.
5. `createOrder` (с `idempotencyKey`): транзакция — списание стока → номер `ORD-YYYY-NNNNN` → снапшоты → очистка корзины. *(orders)*
6. Страница успеха показывает номер заказа (cookie `last_created_order` для гостя).

## Сценарии отказа
- **Товар закончился:** при списании `count===0` → откат, «Недостатньо товару …».
- **Двойной сабмит:** тот же `idempotencyKey` → возвращается существующий номер.
- **Товар деактивирован между шагами:** «Деякі товари більше не доступні».

## Связанные требования
FR-CAT-3/4, FR-PR-2, FR-ORD-1..7, AC-ORD-1..3.

## Пробелы 🔴
- Онлайн-оплата не инициируется (paymentStatus PENDING).
- Доставка не рассчитывается (`shipping=0`).
- Гостю недоступна история заказов (только 5-мин cookie).
