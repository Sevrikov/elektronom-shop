# Права и роли (RBAC) — Elektronom

> Артефакт агента **Detective** (`completo`) · Reversa.
> Источник: `UserRole` enum + хелперы `requireAuth/requireAdmin/requireManager` (`src/lib/auth.ts`) + проверки в server actions. 🟢 — из кода.

## Роли (`UserRole`)
- **CUSTOMER** (default) — покупатель.
- **MANAGER** — определён в enum и в `requireManager()`, но **в действиях не используется** (🟡 находка AD-5/A-?).
- **ADMIN** — полный доступ к админ-функциям.

Сессия — JWT; `role` кладётся в токен и `session.user.role` (callbacks).

## Матрица прав

| Возможность | Гость | CUSTOMER | MANAGER | ADMIN |
|-------------|:-----:|:--------:|:-------:|:-----:|
| Просмотр каталога/товара/поиск | ✅ | ✅ | ✅ | ✅ |
| Гостевая корзина (cookie) | ✅ | — | — | — |
| Серверная корзина (БД) | — | ✅ | ✅ | ✅ |
| Оформить заказ | ✅¹ | ✅ | ✅ | ✅ |
| Просмотр своих заказов | ❌² | ✅ | ✅ | ✅ |
| Wishlist | ❌ | ✅ | ✅ | ✅ |
| Оставить отзыв | ❌ | ✅ | ✅ | ✅ |
| Профиль / смена пароля | ❌ | ✅ | ✅ | ✅ |
| AI-ассистент | ✅ | ✅ | ✅ | ✅ |
| **Админка** (товары/категории/бренды) | ❌ | ❌ | ❌³ | ✅ |
| Заказы (все) / смена статуса | ❌ | ❌ | ❌³ | ✅ |
| Модерация отзывов | ❌ | ❌ | ❌³ | ✅ |
| Загрузка/удаление изображений | ❌ | ❌ | ❌³ | ✅ |
| Запуск Content Factory | ❌ | ❌ | ❌³ | ✅ |

¹ Гость оформляет заказ из cookie-корзины (`userId=null`).
² Гость видит только что созданный заказ по 5-мин cookie `last_created_order`; истории нет.
³ **🟡 MANAGER фактически не имеет доступа к админ-функциям** — все они под `requireAdmin()`, а не `requireManager()`. Роль зарезервирована, но не задействована.

## Точки контроля доступа
- `requireAuth()` → throw `UNAUTHORIZED` (нет сессии).
- `requireAdmin()` → throw `FORBIDDEN`, если `role !== ADMIN`. Используется во **всех** `*Admin`-экшенах и в `api/admin/upload` (POST/DELETE).
- `requireManager()` → ADMIN|MANAGER — **объявлен, но не вызывается** в проде.
- Проверка владения на уровне данных: `getOrderByNumber` (заказ только владельцу), отзыв/wishlist/корзина — по `session.user.id`.

## Замечания и риски
- 🟡 **Неиспользуемая роль MANAGER** — либо удалить из enum, либо ввести `requireManager()` для подмножества админ-операций (заказы/модерация) для разграничения.
- 🟢 RBAC применяется единообразно (server-side), включая API-роуты загрузки.
- 🔴 Нет аудита админ-действий (кто/когда менял статус заказа, удалял отзыв) — только `logger.info`, без отдельной модели аудита.
