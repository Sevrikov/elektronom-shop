# Анализ страницы категории Rozetka: `/ua/notebooks/c80004/`

Дата: 2026-05-26  
Источник: `https://rozetka.com.ua/ua/notebooks/c80004/`  
Цель: разобрать UX/SEO/фасетную структуру страницы раздела и понять, что адаптировать для Elektronom.

---

## 1. Общая структура страницы

Страница устроена как зрелая marketplace category page:

```text
Header / search / catalog
Breadcrumbs
H1 категории
SEO/quick landing links
Toolbar: найдено N товаров + сортировки
Sidebar filters
Product listing
Show more + pagination
Popular reviews block
SEO text / buying guide
Footer
```

Для Elektronom важно повторить не визуальный стиль, а принцип:

- быстрый вход в популярные сценарии;
- много фасетов;
- counts рядом с каждым значением;
- коммерческие признаки на карточках;
- SEO-текст не мешает покупке, находится ниже выдачи.

---

## 2. Верх страницы

### 2.1 Breadcrumbs

На Rozetka перед H1 есть цепочка:

```text
Комп'ютери та ноутбуки / Ноутбуки
```

Для Elektronom:

```text
Головна / Каталог / Електрика / Автоматичні вимикачі
```

Требования:

- breadcrumbs должны быть кликабельными;
- последний элемент не ссылка;
- JSON-LD BreadcrumbList должен совпадать с видимыми breadcrumbs;
- не допускать `/uk/uk`.

### 2.2 H1

Rozetka использует короткий H1:

```text
Ноутбуки
```

Для Elektronom:

```text
Автоматичні вимикачі
Моторні мастила
Акумулятори
Реле контролю напруги
```

Не перегружать H1 SEO-фразой. SEO-фразы уводить в meta title/description и нижний текст.

```text
Для дизеля
Для бензину

```

Для аккумуляторов:


Требования:

- выводить 8-12 ссылок;
- на mobile горизонтальный scroll;
- часть ссылок может вести на фильтрованный URL;
- SEO-важные ссылки лучше делать отдельными landing pages, если они нужны в индексе.

Для Elektronom:

```text
Знайдено 128 товарів
Популярні
Від дешевих
Від дорогих
Новинки

```

Требования:

- количество найденных товаров всегда видно;
- сортировка рядом с количеством;
- на mobile сортировка открывается compact select/menu;
- при применении фильтра `page` сбрасывается;
- `sort` сохраняется при очистке фильтров.

## 5. Sidebar filters

Самая сильная часть страницы Rozetka — длинный фасетный sidebar.

Примеры групп:

- продавец;
- бренд;
- цена;
- специальные предложения;
- доставка;
- процессор;
- RAM;
- видеокарта;
- диагональ;
- SSD;
- ОС;
- класс;
- частота экрана;
- разрешение;
- дополнительные свойства;
- аккумулятор;
- слоты RAM;
- тип экрана;
- видеопамять;
- страна-производитель;
- цвет;
- акции;
- отзывы/рейтинг;
- состояние товара.

Вывод: для технического магазина фильтры должны быть не общими, а **категорийно-специфичными**.

## 7. Фильтр “Показати ще”

Rozetka не показывает сразу весь список брендов/значений. Есть первые популярные значения и кнопка `Показати ще`.

Для Elektronom:

- показывать первые 8 значений;
- дальше `Показати ще`;
- для брендов и длинных списков добавить поиск внутри группы;
- выбранные значения всегда показывать даже если они ниже первых 8.

---

## 8. Цена

Rozetka держит цену отдельным блоком с диапазоном.

Для Elektronom:

- `priceMin`;
- `priceMax`;
- кнопка/auto apply после debounce;
- не отправлять пустые значения;
- если `priceMin > priceMax`, нормализовать или показывать ошибку;
- price chip должен отображаться как `500 — 2500 ₴`.

---

## 9. Коммерческие фильтры

У Rozetka есть отдельные группы:

- товары со спецпредложениями;
- бонусы;
- готово к отправке;
- доставка в магазины;
- акции;
- рейтинг;
- состояние.

Для Elektronom стоит добавить не всё сразу, а по приоритету:

MVP:

- `В наявності`;
- `Акція`;
- `Новинки`;
- `Знижка`;

Later:

- `Є відгуки`;
- `Рейтинг 4+`;
- `Оплата з ПДВ`;
- `Швидка доставка`;
- `Офіційна гарантія`;
- `Для юросіб`;
- `Під замовлення`;
- `Уцінка`.

## 10. Product cards

На карточках Rozetka видны коммерческие признаки:

- бейджи `ТОП ПРОДАЖІВ`, `АКЦІЯ`, `ВИБІР ROZETKA`;
- фото;
- длинное название с ключевыми характеристиками;
- количество отзывов;
- старая цена;
- новая цена;
- доставка;
- бонусы;
- подарок/акция;
- иногда “ещё у N продавцов”.

Для Elektronom карточка категории должна показывать:

- фото товара;
- бейдж `В наявності`, `Акція`, `Топ продажів`;
- бренд;
- название;
- SKU/MPN;
- 3-5 ключевых характеристик;
- цена;
- старая цена/скидка;
- кнопка корзины;
- quick quantity stepper желательно позже;
- наличие/склад;
- рейтинг/отзывы после внедрения отзывов.

## 11. Pagination + “Показати ще”

Rozetka использует:

- `Показати ще`;
- номера страниц;
- `Сторінка 1 з 75`.

Для Elektronom:

MVP:

- pagination как сейчас;

Лучше:

- добавить `Показати ще` над pagination;
- после show more URL может сохранять page или использовать обычную пагинацию;
- для SEO основными должны оставаться пагинированные URL.

---

## 12. Reviews block ниже выдачи

После товаров Rozetka показывает блок популярных отзывов в категории.

Для Elektronom это полезно позже:

```text
Популярні відгуки в категорії
```

Можно выводить 2-4 отзыва по товарам категории:

- товар;
- рейтинг;
- имя;
- дата;
- короткий текст;
- ссылка на товар.

Это повышает доверие и увеличивает внутренние перелинковки.

---

## 13. SEO-текст снизу

Rozetka размещает большой SEO/guide текст внизу страницы:

- вступление;
- преимущества;
- таблица/структура выбора;
- типы товара;
- критерии выбора;
- бренды;
- финальный коммерческий абзац;
- `Читати повністю`.

Для Elektronom:

Не ставить SEO-текст над товарами. Размещать после выдачи.

Структура:

```text
H2: Як вибрати [категорія]
Короткое intro
H3: Основні характеристики
H3: На що звернути увагу
H3: Популярні бренди
H3: Де застосовується
FAQ 3-5 вопросов
```

Для технических категорий лучше делать текст экспертным, а не водянистым.

## 14. Что стоит адаптировать для Elektronom в первую очередь

Приоритет 1:

- quick landing links под H1;
- real attribute filtering;
- counts;
- `Показати ще` в длинных фильтрах;
- mobile filter drawer;
- product cards с ключевыми характеристиками;
- SEO-текст снизу.

Приоритет 2:

- популярные запросы;
- категория reviews block;
- show more + pagination;
- коммерческие фильтры “Акція”, “З ПДВ”, “Швидка доставка”.

Приоритет 3:

- рейтинг/отзывы как фильтр;
- сравнение товаров;
- персональные рекомендации;
- paid/promo placements.

## 16. Главное отличие для Elektronom

Rozetka продаёт массовую категорию “ноутбуки”, поэтому у них фильтры потребительские:

- RAM;
- процессор;
- экран;
- SSD;
- ОС;
- цвет.

Elektronom должен быть более техническим:

- номинал;
- ток;
- напряжение;
- количество полюсов;
- тип монтажа;
- стандарт;
- серия;
- совместимость;
- технический документ;
- наличие на складе;
- возможность оплаты с НДС.

То есть нам нужен не просто “Rozetka style”, а **technical marketplace style**.
