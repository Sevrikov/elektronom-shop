## 3. Экран списка товаров Prom

URL-ориентир: `https://my.prom.ua/cms/product`

### 3.1. Верхний блок

В Prom экран называется `Перелік позицій`. Рядом основные действия:

- `Експорт`;
- `Додати товар`.

Над таблицей есть показатели:

- добавлено товаров;
- добавлено разновидностей;
- опубликовано;
- в каталоге;
- не в каталоге;
- нет фото;
- нет цены.

### Что перенести в Elektronom

Сделать над таблицей товаров KPI-панель:

- Всего товаров;
- Активные;
- Скрытые;
- В наличии;
- Нет в наличии;
- Без фото;
- Без цены;
- Без бренда;
- Без описания;
- Без SEO;
- Featured.

Каждая карточка KPI должна быть кликабельным фильтром.

### 3.2. Сохранённые фильтры

Prom показывает блок:

- `Збережені фільтри`;
- `Всі`;
- количество товаров в фильтре.

### Что перенести

Системные saved filters:

- Все;
- Активные;
- Скрытые;
- Без фото;
- Без цены;
- Нет в наличии;
- Featured;
- Последние добавленные;
- Требуют проверки.

Позже можно добавить пользовательские saved filters.

### 3.3. Таблица

Prom-таблица содержит:

- название;
- дату;
- код/SKU;
- отображение;
- цену;
- заказы;
- действия;
- статус наличия;
- статус публикации;
- категория/группа;
- бренд;
- внешние ссылки на товар.

### Что перенести

Таблица Elektronom должна показывать:

- чекбокс;
- фото;
- название UA/RU;
- storefront link;
- категория;
- бренд;
- SKU;
- активность;
- остаток;
- цена;
- compare price;
- cost price;
- SEO/quality indicators;
- дата обновления;
- количество заказов;
- действия.

## 4. Форма редактирования товара Prom

URL-ориентир: `https://my.prom.ua/cms/product/edit/...`

Prom-форма очень богата. Важные блоки:

### 4.1. Верхние действия

- просмотр позиции;
- копировать;
- сохранить и перейти к списку;
- сохранить изменения;
- удалить позицию.

### 4.2. Основная информация

- название UA;
- название RU;
- автоматический перевод пустых полей;
- ручной перевод UA ↔ RU;
- код/артикул;
- описание UA;
- описание RU;
- rich text editor;
- вставить шаблон;
- создать таблицу;
- лимит символов описания;
- личные заметки.

### 4.3. Тип продажи и цена

- розница;
- только опт;
- опт и розница;
- услуга;
- розничная цена;
- валюта;
- “цена от”;
- единица измерения.

### 4.4. Наличие и остатки

- наличие;
- готово к отправке;
- остатки;
- где находится товар;
- регионы;
- оплатить частями.

### 4.5. Видимость

- опубликовано;
- черновик;
- скрытый;
- дата создания;
- дата обновления.

### 4.6. Медиа

- изображения, лимит 10;
- добавить фото по ссылке;
- видео, лимит 10;
- добавить видео по ссылке.

### 4.7. Размещение

- поисковые запросы UA;
- поисковые запросы RU;
- группа на сайте;
- категория на маркетплейсе;
- автоматически определённые категории.

### 4.8. Характеристики

Prom делит характеристики на:

- характеристики категории, влияющие на фильтры каталога;
- пользовательские характеристики;
- группы характеристик;
- габаритные размеры:
  - ширина;
  - высота;
  - длина;
  - вес;
- подсказки со средним значением по категории.

### 4.9. Продвижение

- добавить скидку;
- добавить подарок;
- добавить ярлык;
- добавить сопутствующие товары.

### 4.10. Разновидности

- включить/выключить разновидности;
- варианты цвета/размера/вида.

### 4.11. Дополнительная информация

- комплектация;
- способ упаковки UA/RU;
- PDF-спецификации;
- загрузить файл;
- GTIN;
- MPN.

### 4.12. SEO

- preview в поисковых системах UA;
- preview в поисковых системах RU;
- SEO title;
- SEO description;
- редактировать SEO.

## 7. Экран характеристик Prom

URL: `https://my.prom.ua/cms/product_attributes`

В Prom:

- таблица всех пользовательских характеристик;
- название RU;
- название UA;
- пагинация;
- редактирование переводов характеристик.

### Что перенести

Для Elektronom нужен раздел `Attributes / Filters`:

- список характеристик;
- ключ `attributeKey`;
- название UA/RU;
- единица измерения;
- тип: checkbox / range / pill / select;
- категории, где используется;
- значения;
- порядок отображения;
- флаг “использовать как фильтр каталога”;
- флаг “показывать в карточке товара”.

Это критично для текущих Rozetka-style фильтров.

## 8. Экран импорта Prom

URL: `https://my.prom.ua/cms/import`

Prom поддерживает:

- импорт с сервера;
- импорт с компьютера;
- форматы Google, XLS, CSV, YML, XML;
- Zip/Gzip;
- лимит файла;
- добавить ссылку;
- настройка полей, которые обновлять:
  - название RU/UA;
  - описание RU/UA;
  - поисковые запросы RU/UA;
  - артикул;
  - цена;
  - фото;
  - наличие;
  - количество;
  - группа;
  - характеристики;
  - скидки;
  - личные заметки;
  - GTIN;
  - MPN;
- общие настройки:
  - обновить принудительно;
  - загружать позиции “в наличии”;
  - только обновление;
  - что делать с товарами, которых нет в файле:
    - оставить без изменений;
    - нет в наличии;
    - скрытые;
    - удалённые;
  - автообновление ссылки:
    - никогда;
    - раз в 4 часа;
- отчёт по импорту:
  - обработано;
  - позиции с ошибками;
  - позиции не могут быть загружены;
  - импорт отменён.

### Что перенести

Не делать полный импорт в Sprint 1, но заложить архитектуру:

- страница `Import`;
- upload XLS/CSV/XML/YML;
- mapping полей;
- dry-run preview;
- отчёт ошибок;
- режим update-only;
- политика отсутствующих товаров.

## 14. Вывод

Prom.ua показывает правильную логику: админка товаров должна быть не “форма редактирования”, а **операторский центр качества каталога**.

Для Elektronom ближайший правильный шаг:

1. усилить список товаров до Prom-like таблицы;
2. добавить KPI качества;
3. добавить фильтры и сохранённые фильтры;
4. разделить большую админку на компоненты;
5. расширить форму товара по секциям;
6. затем перейти к атрибутам и импорту.
