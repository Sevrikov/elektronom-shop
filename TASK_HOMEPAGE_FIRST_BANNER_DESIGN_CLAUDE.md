# ТЗ: дизайн первого баннера для главной карусели Elektronom

## Назначение задачи

Подготовить дизайн первого баннера для главной страницы сайта Elektronom.

Баннер должен заменить текущую пустую промо-зону на главной странице, где сейчас отображается placeholder:

> Промо-зона — буде заповнено акціями та сезонними пропозиціями

Нужен не абстрактный декоративный баннер, а коммерческий hero-баннер в карусель, который сразу показывает товар/категорию, создаёт ощущение живого магазина и ведёт пользователя к покупке.

## Режим работы для Claude Design / дизайнера

Сделать дизайн-концепт баннера.

Не менять код сайта.

Не внедрять баннер в проект.

Результат: дизайн-макет/HTML-preview/описание слоёв + рекомендации для разработчика, какие assets и размеры подготовить.

Если используется Claude Design, задача — создать визуальный концепт баннера и экспортируемую структуру, по которой разработчик сможет сверстать компонент.

## Коммерческая идея первого баннера

Первый баннер должен продвигать **топовый товар или топовую товарную группу**.

Источник выбора товара:

1. Использовать последнюю аналитическую таблицу со скриншота пользователя.
2. Найти соответствующий товар/категорию на сайте Elektronom.
3. Если точный товар не найден, выбрать ближайший релевантный товар/категорию и явно отметить это в отчёте.

Из аналитического скриншота видны кандидаты:

- `Дощувач пульсуючий з повною/частковою зоною поливу на тринозі INTERTOOL GE-0068`
- `Підставка під машину 3 т 288-430 мм INTERTOOL GT0401`
- `Реле проміжне LY2 (AC 220 V) АСКО-УКРЕМ`
- `Повітряний фільтр M20 INTERTOOL PT-9071`
- `Акумуляторна батарея 12В 20Ач Trinix 12V20Ah/20Hr Super Charge AGM`
- `Дріт зварювальний флюсовий GRADIENT`
- `Мікрометр 0-25 мм INTERTOOL`
- `Пристрій захисного відключення UTrust 1P+N 40A 30mA`

## Инфографическая тематика баннера

Баннер должен быть не просто “товар на фоне”, а **товарно-инфографическим hero**.

Идея: соединить коммерческий баннер и понятные числовые/технические сигналы, которые сразу объясняют ценность товара или группы.

### Что такое инфографический баннер в этом ТЗ

Это баннер, где рядом с товаром есть 2-4 коротких визуальных факта:

- техническая характеристика;
- выгода;
- наличие;
- сценарий применения;
- категория;
- популярность;
- скидка, если она реально есть;
- доставка/опт, если это подтверждено данными.

### Не использовать фальшивые цифры

Все цифры должны быть подтверждены:

- страницей товара;
- аналитическим скриншотом;
- данными сайта;
- отдельным подтверждением владельца.

Если данных нет, писать нейтральные формулировки без цифр.

Разрешено:

```text
В наявності
Для автоматики
Для резервного живлення
Опт і роздріб
Швидка доставка по Україні
```

Запрещено без подтверждения:

```text
№1 в Україні
до 70% економії
10 000 продажів
найкраща ціна
гарантовано найнижча ціна
```

Можно показать 2-3 маленьких data chips на основе топ-списка, но без перегруза:

```text

Високий попит
Популярні позиції тижня
```

Если дизайнер использует числа из аналитического скриншота, подписывать их аккуратно:

```text

```

Но использовать такие цифры только если владелец подтверждает, что эти метрики можно публично показывать.

Для публичного баннера безопаснее не показывать внутренние цифры аналитики, а использовать их только для выбора товара.

### Визуальный стиль инфографики

Инфографика должна быть компактной:

- chips/pills с лёгким фоном;
- тонкие линии-указатели к товару;
- small stat cards;
- иконки Lucide-like;
- без больших таблиц;
- без “dashboard UI” внутри баннера.

Пример:

```text
[40 A] [30 mA] [Тип A] [В наявності]
```

или:

```text
AC 220 V    10 A    Для автоматики
```

Не делать инфографику слишком мелкой: на mobile часть chips можно скрыть или заменить одной строкой.

## Визуальное направление

### Общий характер

Баннер должен ощущаться:

- техническим;
- современным;
- энергичным;
- товарным;
- доверительным;
- не “маркетингово-пустым”.

Не должен выглядеть:

- как крипто/гейминг баннер;
- как случайная стоковая абстракция;
- как дешёвая рекламная листовка;
- как полностью чужой стиль относительно главной Elektronom.

### Композиция desktop

Desktop-баннер должен быть горизонтальным.

Рекомендуемая композиция:

- левая часть: текст, badge, CTA;
- правая часть: крупный товар или группа товаров;
- фон: светло-синий/электрический технический фон;
- снизу/сбоку: тонкие линии, сетка, намёк на DIN-рейку, электрические импульсы;
- товар не должен быть мелким;
- CTA должен быть виден сразу.
- инфографические chips должны поддерживать товар, а не спорить с заголовком.

Примерная структура:

```text
┌─────────────────────────────────────────────────────────────┐
│ [Топ продажів]                                               │
│ Автоматика, що тримає живлення під контролем      [товар]    │
│ ПЗВ, реле, перемикачі та рішення для стабільної   [товар]    │
│ роботи електромережі                              [товар]    │
│ [40 A] [30 mA] [Тип A] [В наявності]                         │
│ [Перейти до товарів] [Дивитись каталог]                      │
└─────────────────────────────────────────────────────────────┘
```

### Композиция mobile

На мобильном баннер не должен просто сжиматься.

Рекомендуемая mobile-композиция:

- сверху badge;
- далее короткий заголовок в 2-3 строки;
- товар крупно, но не перекрывает текст;
- CTA внизу;
- максимум 1-2 инфографических chips;
- без мелких декоративных надписей;
- высота не должна занимать весь экран.

Пример:

```text
[Топ продажів]
Автоматика для стабільного живлення
[крупный товар]
[40 A] [30 mA]
[Перейти до товарів]
```

## Размеры и адаптивы

Подготовить дизайн минимум в трёх форматах.

### Desktop

Целевой размер для главной зоны:

- ширина примерно `1020px`;
- высота примерно `300-340px`;
- aspect ratio около `3:1`.

Также желательно подготовить export-friendly размер:

- `1440x420`
- `1536x448`

### Tablet

- `768x320`
- допускается перестройка товара и текста.

### Mobile

- `390x220`
- `430x240`

Для мобильного не использовать мелкий текст меньше `12px`.

## Контентные требования

### Язык

Основная версия: украинский.

В дизайне использовать украинские тексты.

Если будет предусмотрена русская версия, подготовить отдельные тексты позже.

### Текст на баннере

Не перегружать баннер.

Максимум:

- 1 badge;
- 1 headline;
- 1 short subtitle;
- 1 CTA;
- 1 вторичная ссылка или маленькая trust-фраза.

Не использовать длинные списки характеристик.

### Пример финального текста

```text
Топ продажів

Автоматика, що тримає живлення під контролем

ПЗВ, реле, перемикачі та рішення для стабільної роботи електромережі

Перейти до товарів
```

## Работа с товаром

### Главное правило

Использовать реальный товар/категорию с сайта Elektronom.

Не выдумывать бренд, модель и цену.

Если точный товар из аналитического скриншота не найден на сайте:

- указать “точный товар не найден”;
- предложить ближайшую категорию;
- не писать фальшивую цену;
- не писать “знижка”, если её нет в данных.

### Возможные товарные направления

1. `Реле проміжне LY2 (AC 220 V) АСКО-УКРЕМ`
2. `Пристрій захисного відключення UTrust 1P+N 40A 30mA`
3. `Акумуляторна батарея 12В 20Ач Trinix`
4. `Автоматичні вимикачі`
5. `Резервне живлення`
6. `Інструмент INTERTOOL`

### Изображения

Желательно использовать:

- реальные product images из сайта;
- изображения из `public/images/products/`, если они соответствуют товару;
- чистый PNG/WebP товара на прозрачном или светлом фоне;
- не растягивать маленькое изображение до мыла.

Если реального изображения нет:

- предложить задачу на подготовку product cutout;
- можно временно использовать AI-generated technical product mockup, но обязательно отметить, что это placeholder.

## Стиль фона

Фон должен быть более выразительным, чем текущий placeholder, но совместимым с Elektronom.

Разрешено:

- светло-синий технический градиент;
- мягкие электрические линии;
- абстрактная DIN-рейка;
- сетка/чертёж;
- легкий glow около товара;
- subtle motion lines;
- техническая глубина.

Не использовать:

- тёмный однотонный синий на весь баннер без светлых зон;
- кислотные цвета;
- фиолетово-синие “AI orbs”;
- bokeh blobs;
- слишком много бликов;
- фон, который мешает читать текст;
- stock-like людей в касках;
- случайные 3D-иконки без связи с товаром.

## Палитра

Основная:

- `#3B7BD9` — accent blue;
- `#2C67BE` — hover/deep blue;
- `#1A1F2B` — primary text;
- `#FFFFFF` — text/card contrast;
- `#F5F7FA` — soft background;
- `#E8EEF7` — subtle accent surface.

Дополнительные акценты:

- `#DC2626` — только для small badge “Новинка” или “Топ”, не доминировать;
- `#2A9D4A` — availability/trust;
- холодный cyan glow допустим очень умеренно.

## Типографика

Шрифт: Inter или визуально совместимый sans-serif.

Desktop:

- headline: `34-44px`, bold/extrabold;
- subtitle: `15-18px`;
- CTA: `14-16px`, semibold.

Mobile:

- headline: `22-28px`;
- subtitle: `13-15px`;
- CTA: `14-15px`.

Не использовать отрицательный letter-spacing.

Не использовать слишком узкие/агрессивные display fonts.

## UI-ограничения под сайт

Баннер должен встраиваться в текущую главную:

- radius не больше `8px`, если это UI-контейнер;
- не делать карточку внутри карточки;
- не использовать слишком тяжёлую рамку;
- стрелки слайдера должны быть аккуратными;
- dots карусели должны быть минимальными;
- CTA должен быть в стиле сайта: синий solid button.

## Требования к карусели

Дизайн должен учитывать, что баннер будет первым слайдом в carousel.

Нужно предусмотреть:

- left/right arrows;
- pagination dots;
- hover/active state;
- mobile swipe;
- отсутствие перекрытия arrows с текстом;
- отсутствие перекрытия arrows с товаром.

Стрелки должны быть нейтральными, как сейчас на сайте:

- белый круг;
- тонкая тень/бордер;
- иконка chevron;
- не доминировать.

Баннер можно принимать, если:

- он похож по энергии на товарные баннеры Triniti, но не копирует их;

- товарная ссылка указана и проверена;
- инфографические цифры/характеристики не выдуманы;
